# Batch 18 Korean editorial drafts

These tools decode a single image in the browser and export a separate Canvas image. Inputs are limited to 30 MB and decoded images to 40 million pixels; original pixel data is not overwritten.

## image-resize

- **소개와 원리:** 너비와 높이를 지정해 Canvas에서 새 픽셀 크기로 다시 그립니다. 비율 유지가 켜져 있으면 너비를 기준으로 높이를 계산합니다.
- **활용과 절차:** 큰 사진을 문서나 웹용 크기로 줄이려면 이미지와 목표 너비를 지정하고 비율 유지 여부를 확인한 뒤 실행합니다.
- **예제:** 1600×1200에 너비 800과 비율 유지를 적용하면 800×600 픽셀입니다.
- **제한과 결과:** 각 목표 변은 1~12,000 픽셀 범위입니다. 확대는 세부 정보를 새로 만들지 않습니다. 결과는 별도 JPEG 파일입니다.
- **문제 해결과 FAQ:** 높이 입력이 비활성화된 경우 비율 유지가 켜진 것입니다. 원본은 그대로이고 결과 화질은 JPEG 재인코딩 영향을 받습니다.

## image-crop

- **소개와 원리:** 선택한 1:1, 16:9, 3:4 비율 중 입력 이미지 중앙에서 맞는 사각 영역을 잘라 Canvas로 내보냅니다.
- **활용과 절차:** 프로필용 정사각형이나 가로 배너를 만들려면 이미지와 비율을 고르고 실행한 뒤 가장자리 구성을 확인합니다.
- **예제:** 1200×800 사진에서 1:1을 고르면 중앙의 800×800 영역이 결과가 됩니다.
- **제한과 결과:** 직접 자를 위치나 크기를 드래그하는 편집 기능은 없습니다. 가장자리의 바깥 영역은 결과에 포함되지 않고 JPEG 파일로 저장됩니다.
- **문제 해결과 FAQ:** 예상과 다른 부분이 잘리면 선택 비율과 원본 중심을 확인하세요. 결과 위치를 옮기려면 원본 구도를 미리 조정해야 합니다.

## image-rotate

- **소개와 원리:** Canvas에서 이미지를 90°, 180°, 270° 회전해 새 JPEG로 내보냅니다. 90°와 270°는 가로·세로 픽셀 수가 서로 바뀝니다.
- **활용과 절차:** 방향이 잘못된 사진을 세로 또는 가로 방향으로 바꾸려면 파일을 선택하고 회전 각도를 골라 실행합니다.
- **예제:** 640×480 이미지를 90° 돌리면 480×640 결과가 됩니다.
- **제한과 결과:** 회전은 90도 단위 선택이며 임의 각도나 EXIF 방향 메타데이터 수정 기능은 아닙니다. 재인코딩으로 화질과 메타데이터가 달라질 수 있습니다.
- **문제 해결과 FAQ:** 픽셀 크기가 예상과 다르면 선택 각도를 확인하세요. 원본은 보존되고 회전된 파일을 따로 받습니다.

## image-flip

- **소개와 원리:** Canvas 좌표를 수평 또는 수직으로 뒤집어 별도 JPEG로 출력합니다. 이미지 크기는 바뀌지 않습니다.
- **활용과 절차:** 거울 반전이 필요한 이미지에서 가로 또는 세로 방향을 선택하고 실행한 뒤 결과 방향을 확인합니다.
- **예제:** 640×480 이미지를 수평 뒤집으면 같은 640×480 크기에서 좌우가 바뀝니다.
- **제한과 결과:** 회전이나 자유 변형, 원근 수정은 하지 않습니다. JPEG로 다시 인코딩되며 입력은 30MB·4천만 픽셀 이내여야 합니다.
- **문제 해결과 FAQ:** 변화가 보이지 않으면 대칭에 가까운 원본인지 확인하고 비대칭 물체가 있는 이미지를 시험합니다.

## image-grayscale

- **소개와 원리:** Canvas의 `grayscale(1)` 필터를 적용해 색상 이미지를 회색조로 그린 뒤 JPEG로 내보냅니다. 크기는 유지됩니다.
- **활용과 절차:** 문서용 흑백 이미지나 색상 없는 미리보기가 필요하면 파일을 선택해 실행하고 결과를 확인합니다.
- **예제:** 640×480 컬러 사진 → 640×480 회색조 JPEG.
- **제한과 결과:** 밝기·대비 슬라이더나 흑백 임계값 조정은 제공하지 않습니다. 색상 채널은 회색조로 합쳐지고 원본은 보존됩니다.
- **문제 해결과 FAQ:** 결과가 컬러로 보이면 올바른 파일을 열었는지 확인하세요. 이 도구는 색만 바꾸고 크기 조정은 하지 않습니다.
