## random-name-picker

- 소개·원리: 줄마다 입력한 이름 가운데 한 명 이상을 무작위로 선택합니다. 빈 줄은 제외하고, 같은 이름이 여러 줄에 있으면 별도 참가 항목으로 취급합니다.
- 활용·예제: 경품 당첨자를 뽑을 때 참가자 이름을 한 줄씩 넣고 필요한 인원수를 지정합니다. 중복 당첨을 허용하지 않으면 한 참가 항목은 한 번만 선택됩니다.
- 사용: 참가자 목록과 추첨 인원수를 입력하고, 반복 당첨 여부와 선택된 이름을 목록에서 제거할지 정한 뒤 실행합니다. 목록 섞기는 현재 이름 순서만 바꿉니다.
- 해석·제한: 중복 당첨을 끄면 요청 인원이 목록 항목 수보다 많을 수 없습니다. 같은 이름이 두 줄에 있으면 화면에서 동일한 이름이 두 번 보일 수 있습니다.
- 문제 해결·FAQ: 추첨이 되지 않으면 빈 줄 외에 이름이 있는지, 인원수가 가능한 범위인지 확인합니다. 당첨자 제거는 뽑힌 이름과 일치하는 목록 항목을 하나씩 제거합니다.

## draw-lots

- 소개·원리: 한 줄에 하나씩 적은 항목을 참가 단위로 보고 무작위 추첨합니다. 공백 줄은 건너뛰며 입력 순서와 무관하게 결과를 섞습니다.
- 활용·예제: 여러 신청 중 선정 인원을 정할 때 명단과 뽑을 수를 입력하세요. 반복을 끄면 서로 다른 명단 항목이 선택됩니다.
- 사용: 항목마다 새 줄을 사용하고 추첨 수를 지정합니다. 필요한 경우 중복 선택을 허용하거나 당첨 항목을 원본 목록에서 제거하도록 설정합니다.
- 해석·제한: 중복 허용 시 같은 항목이 여러 번 선택될 수 있고, 요청 수는 최대 100입니다. 중복을 허용하지 않으면 항목 수를 넘는 추첨은 유효하지 않습니다.
- 문제 해결·FAQ: 결과가 예상보다 적으면 빈 줄을 제외한 항목 수와 중복 옵션을 확인하세요. 같은 문구가 여러 줄에 있으면 각 줄은 독립 항목입니다.

## random-wheel

- 소개·원리: 입력한 선택지를 원형 구간으로 표시하고 회전 애니메이션이 끝난 위치의 항목을 선택합니다. 빈 줄은 무시하며 기본 설정에서는 중복 항목을 제거합니다.
- 활용·예제: 메뉴, 활동, 차례 중 하나를 고를 때 선택지를 줄마다 입력하고 돌리기를 실행합니다. 중복을 허용하면 같은 문구의 줄은 각각 별도 구간이 되어 선택 비중이 커집니다.
- 사용: 최소 두 항목을 입력하고 필요하면 중복 허용, 회전 속도, 당첨 항목 제거 설정을 조정한 뒤 돌립니다. 속도는 3초·5초·8초 중 선택합니다.
- 해석·제한: 한 번에 2–50개 선택지를 사용할 수 있습니다. 당첨 항목 제거를 켜면 회전이 끝난 다음 일치하는 첫 항목 한 줄을 목록에서 지웁니다.
- 문제 해결·FAQ: 실행 버튼이 비활성화되면 항목이 두 개 이상인지, 50개를 넘지 않았는지 확인하세요. 빈 줄을 정리하고 중복 제거 버튼으로 같은 항목을 합칠 수 있습니다.

## random-team-maker

- 소개·원리: 참가자 목록을 무작위로 섞은 뒤 선택한 팀 수 또는 팀당 인원수에 맞춰 순환 배분합니다. 공백 줄은 제외하고 모든 유효 참가자를 배정합니다.
- 활용·예제: 여섯 명을 두 팀으로 나누면 두 팀에 세 명씩 배정됩니다. 팀당 인원수를 선택하면 마지막 팀은 나머지 인원만 포함할 수 있습니다.
- 사용: 한 줄에 참가자 한 명을 입력하고 팀 수 기준 또는 팀 크기 기준을 선택합니다. 원하면 팀 이름을 줄마다 적고 나누기를 실행합니다.
- 해석·제한: 팀 수는 참가자 수를 넘을 수 없으며 참가자가 없으면 계산할 수 없습니다. 결과는 매번 무작위로 재배치되고 공정성이나 실력 균형을 평가하지 않습니다.
- 문제 해결·FAQ: 팀이 생성되지 않으면 이름을 입력했는지와 설정한 팀 수·팀 크기가 유효한지 확인하세요. 빈 줄은 참가자 수와 배정에서 제외됩니다.

## random-order

- 소개·원리: 줄마다 입력한 참가자를 무작위 순서로 섞고 결과를 처음에는 한 명씩 공개합니다. 빈 줄은 제외하지만 중복 이름은 별도 항목으로 남습니다.
- 활용·예제: 발표 순서를 정할 때 이름을 한 줄씩 입력하고 순서 생성을 누릅니다. 첫 항목을 확인한 뒤 다음 사람을 하나씩 공개하거나 전체 결과를 볼 수 있습니다.
- 사용: 참가자 목록을 입력해 순서를 만든 다음 다음 순서 공개 또는 전체 공개를 사용합니다. 번호 표시를 켜면 현재 공개 순서에 번호가 붙고 전체 결과를 복사할 수 있습니다.
- 해석·제한: 번호는 생성된 순서의 위치를 표시하며 참가자에게 고정 번호를 부여하지 않습니다. 같은 입력이라도 다시 생성하면 다른 순서가 나올 수 있습니다.
- 문제 해결·FAQ: 결과가 비어 있으면 이름이 빈 줄이 아닌 실제 텍스트로 입력됐는지 확인하세요. 같은 이름을 여러 번 입력했다면 각각 별도의 순서 위치를 차지합니다.
