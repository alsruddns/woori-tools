# Batch 16 Korean editorial drafts

Drafts reflect the client-side Prettier/Marked workspaces and Canvas conversion path.

## javascript-formatter

- **소개·원리:** Prettier의 Babel 및 ESTree 플러그인으로 JavaScript 소스를 100열 기준으로 정리합니다. 코드를 실행하지 않습니다.
- **활용·사용:** 압축된 코드를 검토하거나 공유하기 쉽게 정돈할 때 붙여 넣고 실행합니다.
- **예제:** `const x=1;` → `const x = 1;`.
- **제한·문제 해결:** 구문을 파싱할 수 있어야 정리됩니다. 포맷 성공은 타입 검사나 런타임 검증이 아닙니다. 오류가 나면 괄호, 따옴표와 입력 누락을 확인하세요.
- **FAQ:** 코드를 실행하나요? 아니요. 입력한 소스를 포맷합니다. / TypeScript도 검사하나요? 아니요. JavaScript Babel 파서로 포맷하며 타입 검사는 하지 않습니다.

## markdown-preview

- **소개·원리:** Marked로 Markdown을 HTML로 변환하고 DOMPurify의 HTML 프로필로 정화한 뒤 미리보기 영역에 표시합니다. 라이브러리는 실행 버튼을 누를 때 불러옵니다.
- **활용·사용:** 제목과 강조 문법을 확인하려면 `# Hello`와 `**world**`를 입력하고 실행합니다. 미리보기에 제목과 굵은 글자가 보입니다.
- **결과 해석:** 원문 텍스트가 미리보기 HTML로 바뀝니다. 결과를 별도 파일로 내보내는 기능은 확인되지 않았습니다.
- **제한·문제 해결:** 미리보기는 sanitizer가 허용하는 HTML 프로필에 한정됩니다. 외부 사이트 렌더링이나 문서 변환 기능은 아닙니다. 출력이 비어 있으면 다시 실행하고 문법을 확인하세요.
- **FAQ:** 입력한 Markdown을 다른 사람에게 전송하나요? 코드에서 브라우저 내 처리만 확인되며 외부 전송 경로는 없습니다. / 원시 HTML도 그대로 렌더링하나요? Marked 변환 뒤 DOMPurify로 정화된 결과만 표시합니다.

## jpg-to-png

- **소개·원리:** 브라우저가 디코딩할 수 있는 이미지를 Canvas에 그린 뒤 PNG로 인코딩합니다. 입력의 픽셀 너비와 높이는 유지됩니다.
- **활용·사용:** JPEG 그림을 PNG 결과 파일로 받아 다른 문서나 그래픽 작업에 사용할 수 있습니다. 이미지를 선택하고 실행한 뒤 별도 결과를 다운로드합니다.
- **예제:** 320×240 이미지 → 320×240 PNG. 결과 파일명은 `photo-jpg-to-png.png` 형식입니다.
- **제한·문제 해결:** 입력 파일은 30MB 이하, 디코딩된 픽셀은 4천만 이하입니다. 브라우저 디코딩을 지원하지 않는 파일은 처리할 수 없습니다. 크기 초과 시 작은 이미지를 선택하세요.
- **FAQ:** 원본 파일을 덮어쓰나요? 아니요. 새 다운로드를 만듭니다. / 품질 슬라이더가 PNG 압축을 바꾸나요? Canvas PNG 출력은 품질 인수를 사용하지 않습니다.

## png-to-jpg

- **소개·원리:** 디코딩한 이미지를 Canvas에서 JPEG로 다시 인코딩합니다. 투명 영역이 있다면 흰색 배경을 먼저 칠합니다.
- **활용·사용:** PNG 이미지를 JPEG 파일이 필요한 문서 흐름에 맞춰 변환합니다. 파일을 선택해 실행하고 새 결과를 받습니다.
- **예제:** 투명 배경 PNG → 같은 크기의 흰 배경 JPEG. 크기는 30MB 미만, 4천만 픽셀 이하에서 처리됩니다.
- **제한·문제 해결:** 투명도는 JPEG에 보존되지 않으며 흰색으로 합쳐집니다. 브라우저에서 열 수 없는 형식은 실패할 수 있습니다. 출력 품질은 도구의 품질 설정에 따라 달라집니다.
- **FAQ:** 투명 배경을 유지하나요? 아니요. 흰색으로 채운 뒤 JPEG로 저장합니다. / 변환하면서 크기를 조절하나요? 아니요. 입력 이미지의 너비와 높이를 사용합니다.

## webp-to-jpg

- **소개·원리:** 브라우저에서 디코딩한 이미지를 Canvas에 그리고 JPEG로 인코딩합니다. 변환 전에 캔버스를 흰색으로 채웁니다.
- **활용·사용:** WebP 이미지를 JPEG만 받는 편집기나 문서 작업에 맞춰 새 파일로 저장합니다.
- **예제:** 640×480 WebP → 640×480 흰 배경 JPEG. 결과 이름은 `photo-webp-to-jpg.jpg` 형식입니다.
- **제한·문제 해결:** 입력 30MB, 디코딩 4천만 픽셀 한도이며 투명 픽셀은 흰색이 됩니다. 결과 용량은 사진과 품질 설정에 따라 다릅니다. 브라우저가 읽을 수 있는 파일인지 확인하세요.
- **FAQ:** WebP 파일을 그대로 이름만 바꾸나요? 아니요. Canvas에서 픽셀을 다시 인코딩합니다. / 원본을 삭제하나요? 아니요. 별도 JPEG를 만듭니다.
