# Batch 21 Korean editorial drafts

## pdf-split

- **소개와 원리:** PDF에서 지정한 페이지만 골라 새 PDF로 복사합니다. 페이지 번호와 범위는 입력한 순서대로 결과에 배치되며, 중복 번호는 한 번만 포함됩니다.
- **활용과 절차:** 계약서의 서명 페이지와 첨부표만 따로 전달할 때 파일을 선택하고 `3, 1-2`처럼 페이지를 입력한 뒤 실행합니다.
- **검증 예제:** 5쪽 파일에서 `4, 1-2`를 지정하면 결과는 원본 4쪽, 1쪽, 2쪽 순서의 3쪽 PDF입니다.
- **결과 해석:** 결과 페이지 수는 입력 목록의 고유 페이지 수입니다. 원본 페이지의 크기와 내용은 복사되고 새 파일로 다운로드됩니다.
- **제한과 문제 해결:** 번호는 1부터 시작하며 파일의 페이지 수를 넘을 수 없습니다. 빈 입력이나 잘못된 범위는 거부됩니다. 한 번에 PDF 하나, 최대 50MB까지 처리합니다.
- **FAQ:** 페이지 번호를 `4, 1-2`로 입력하면 원래 순서로 정렬되나요? 아니요. 입력한 순서가 결과 순서가 됩니다.

## pdf-delete-pages

- **소개와 원리:** 지정한 페이지를 제거하고 나머지 페이지를 원본 순서대로 새 PDF에 복사합니다.
- **활용과 절차:** 배포 전 표지나 빈 페이지를 제거하려면 PDF를 선택하고 `1, 4-5`처럼 삭제할 번호와 범위를 입력합니다.
- **검증 예제:** 5쪽 파일에서 `2, 4-5`를 삭제하면 1쪽과 3쪽이 순서대로 남은 2쪽 PDF가 생성됩니다.
- **결과 해석:** 입력 목록은 삭제 대상입니다. 결과에는 선택하지 않은 페이지만 담기며 원본은 그대로 유지됩니다.
- **제한과 문제 해결:** 전체 페이지를 지우는 요청은 빈 PDF가 되므로 처리할 수 없습니다. 번호는 1부터 페이지 수 이내여야 하며, 한 PDF 최대 50MB입니다.
- **FAQ:** 삭제할 페이지를 `5, 2`처럼 순서와 다르게 입력해도 남은 페이지 순서가 바뀌나요? 아니요. 남은 페이지는 원본 순서를 유지합니다.

## pdf-reorder-pages

- **소개와 원리:** 새 순서에 따라 PDF의 모든 페이지를 다시 복사합니다. 출력 번호 목록은 원본 페이지 번호를 가리킵니다.
- **활용과 절차:** 스캔 순서가 뒤섞인 문서를 바로잡으려면 페이지가 3장일 때 `3, 1, 2`처럼 전체 순열을 입력합니다.
- **검증 예제:** 크기가 각각 72×36, 100×60, 120×80인 3쪽 PDF에 `3, 1, 2`를 지정하면 출력 크기는 120×80, 72×36, 100×60 순입니다.
- **결과 해석:** 모든 페이지를 정확히 한 번씩 나열해야 합니다. 결과 페이지의 크기와 내용은 해당 원본 페이지를 따릅니다.
- **제한과 문제 해결:** 번호를 빠뜨리거나 반복하거나 범위를 벗어나면 실행되지 않습니다. 쉼표 또는 공백으로 구분하고, 한 PDF 최대 50MB입니다.
- **FAQ:** 일부 페이지만 나열해도 나머지는 뒤에 붙나요? 아니요. 전체 페이지 수와 같은 길이의 완전한 순서를 입력해야 합니다.

## pdf-rotate-pages

- **소개와 원리:** 모든 페이지에 선택한 회전 각도를 현재 방향에 더하고 새 PDF로 저장합니다.
- **활용과 절차:** 가로 방향으로 잘못 스캔된 문서를 바로 세우려면 파일을 선택하고 90°, 180°, 270° 중 필요한 회전을 고릅니다.
- **검증 예제:** 회전값이 0°인 72×36 페이지에 90°를 적용하면 회전 정보가 90°가 됩니다. 페이지 상자 크기는 그대로이고 뷰어가 회전을 표시합니다.
- **결과 해석:** 회전은 페이지의 표시 방향을 바꾸며 내용을 이미지로 다시 그리지 않습니다. 이 선택은 모든 페이지에 적용됩니다.
- **제한과 문제 해결:** 페이지마다 서로 다른 각도를 지정할 수 없습니다. 이미 회전된 문서는 기존 각도에 새 각도가 더해집니다. 한 PDF 최대 50MB입니다.
- **FAQ:** 회전 후 PDF 페이지 너비와 높이 값도 서로 바뀌나요? 아니요. 페이지 크기는 유지되고 회전 메타데이터가 뷰어의 표시 방향을 바꿉니다.

## pdf-add-page-numbers

- **소개와 원리:** 각 페이지 아래쪽에 1부터 시작하는 페이지 번호를 반투명한 회색 Helvetica 글꼴로 그립니다.
- **활용과 절차:** 인쇄하거나 검토할 문서에서 페이지를 쉽게 참조하려면 PDF를 선택하고 실행합니다. 별도 번호 설정은 필요하지 않습니다.
- **검증 예제:** 3쪽 문서에는 첫째 페이지 `1`, 둘째 `2`, 셋째 `3`이 아래쪽 중앙 부근에 추가됩니다.
- **결과 해석:** 번호는 새 PDF 페이지의 실제 그래픽 콘텐츠로 들어가며 원본 파일은 변경되지 않습니다.
- **제한과 문제 해결:** 번호 위치와 글꼴 크기는 고정이고 페이지의 기존 하단 내용을 확인하지 않습니다. 겹침이 우려되면 사본에서 먼저 확인하고 한 PDF 50MB 이내로 선택합니다.
- **FAQ:** 번호가 원본 페이지에 이미 인쇄된 번호를 교체하나요? 아니요. 기존 내용은 그대로 두고 새 번호를 추가합니다.
