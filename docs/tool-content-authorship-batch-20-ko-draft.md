# Batch 20 Korean editorial drafts

## image-info

- **소개와 원리:** 브라우저가 이미지를 디코딩해 파일명, 브라우저 MIME 유형, 픽셀 너비·높이, 원본 파일 크기, 가로세로 비율을 표시합니다.
- **활용과 절차:** 업로드 전 사진 치수를 확인하려면 파일을 선택하고 실행해 픽셀 크기와 비율을 읽습니다.
- **예제:** `photo.png`, image/png, 1200×800px → 비율 1.500:1. 결과의 파일 크기는 원본 바이트를 KiB로 표시합니다.
- **제한과 해석:** 파일 MIME은 브라우저의 File.type 값이므로 비어 있을 수 있습니다. EXIF·GPS나 카메라 정보는 읽지 않습니다.
- **FAQ:** 이미지를 서버에 보내나요? / 아니요. 브라우저에서 디코딩하고 표시합니다.

## favicon-generator

- **소개와 원리:** 선택한 이미지를 Canvas에서 32×32 픽셀로 다시 그려 PNG favicon 파일로 만듭니다.
- **활용과 절차:** 작은 웹사이트 아이콘 시안을 만들려면 이미지를 고르고 실행한 뒤 별도 PNG를 다운로드합니다.
- **예제:** 128×128 정사각 PNG → 32×32 PNG favicon.
- **제한과 결과:** 32×32 단일 크기만 만듭니다. 원본 비율과 달라도 정사각형으로 그리며 ICO 묶음이나 여러 크기 파일을 만들지 않습니다. 입력은 30MB, 디코딩 이미지는 4천만 픽셀까지입니다.
- **FAQ:** 브라우저 탭용 다중 크기 ICO를 만드나요? / 아니요. 이 도구는 32×32 PNG 하나를 내보냅니다.

## image-color-picker

- **소개와 원리:** 선택한 이미지를 미리보기 캔버스에 그리고 클릭한 지점의 픽셀을 읽어 대문자 HEX와 RGB 값으로 보여줍니다. 미리보기 너비는 최대 800px입니다.
- **활용과 절차:** 화면에 보이는 색을 알아보려면 파일을 고른 뒤 미리보기에서 해당 위치를 클릭합니다.
- **예제:** 순수 빨강 픽셀을 클릭 → `#FF0000 · RGB(255, 0, 0)`.
- **제한과 결과:** 클릭 결과는 실제 크기 원본이 아니라 크기 조정된 미리보기 캔버스에서 샘플링됩니다. 매우 큰 이미지의 보간된 색은 인접 원본 픽셀과 다를 수 있습니다.
- **FAQ:** RGB 외에 HSL이나 색상 이름도 표시되나요? / 아니요. HEX와 RGB만 표시합니다.

## images-to-pdf

- **소개와 원리:** 선택한 각 이미지를 브라우저에서 PNG로 그린 다음 PDF 문서에 한 페이지씩 넣습니다. 페이지 크기는 이미지 픽셀 너비와 높이를 사용합니다.
- **활용과 절차:** 스캔 이미지나 그림을 한 PDF로 모으려면 여러 파일을 선택하고 실행한 뒤 생성된 PDF를 다운로드합니다. 선택 순서대로 페이지가 만들어집니다.
- **예제:** 800×600 PNG와 400×300 JPEG → 2페이지 PDF.
- **제한과 결과:** 파일 총합은 50MB 이하, 각 디코딩 이미지는 4천만 픽셀 이하여야 합니다. JPEG 투명 영역은 없고 투명한 PNG는 PDF 페이지에서 투명도를 유지할 수 있습니다. 결과는 별도 PDF입니다.
- **FAQ:** 이미지를 서버로 업로드하나요? / 아니요. PDF 생성은 브라우저에서 수행합니다.

## pdf-merge

- **소개와 원리:** 브라우저에서 선택한 PDF들을 읽고 각 문서의 모든 페이지를 새 PDF에 순서대로 복사합니다.
- **활용과 절차:** 보고서 여러 개를 합치려면 파일을 원하는 순서로 선택하고 실행한 뒤 병합된 PDF를 확인합니다. 각 입력 파일의 페이지 순서도 유지됩니다.
- **예제:** 2페이지 PDF와 3페이지 PDF → 선택 순서대로 총 5페이지.
- **제한과 결과:** 선택한 PDF의 총 크기는 50MB까지입니다. 지원되지 않거나 손상된 문서는 읽지 못할 수 있습니다. 원본을 덮어쓰지 않고 새 파일을 만듭니다.
- **FAQ:** 문서 안의 페이지 순서를 바꾸나요? / 아니요. 파일 선택 순서와 각 문서 페이지 순서를 그대로 사용합니다.
