# Batch 14 Korean editorial drafts

Drafts are based on the shared ZIP/file renaming workspace and text processor/regex worker.

## zip-files

- **소개·원리:** 여러 파일의 원본 바이트를 브라우저에서 읽고 ZIP 아카이브로 묶어 다운로드합니다. 아카이브 항목 이름의 충돌은 고유한 이름으로 정리합니다.
- **활용·사용:** 문서와 이미지 같은 파일을 한 번에 전달할 묶음으로 만들 때 사용합니다. 파일을 선택하고 실행해 ZIP을 받은 뒤 압축을 풀어 파일 목록을 확인합니다.
- **예제:** `notes.txt`와 `photo.jpg`를 선택하면 두 파일이 들어 있는 `zip-files.zip`을 내려받습니다.
- **제한·문제 해결:** 파일 도구는 최대 100개, 합계 200MB까지 선택할 수 있습니다. 압축은 레벨 3으로 처리합니다. 실패하면 수량이나 크기를 줄이세요. 원본 파일을 수정하지 않고 서버로 업로드하지 않습니다.
- **FAQ:** 폴더 전체를 아카이브하나요? 선택한 파일을 묶어 ZIP으로 만듭니다. / ZIP을 풀어 주나요? 아니요. 아카이브를 만들고 다운로드합니다.

## bulk-file-renamer

- **소개·원리:** ZIP 안에 담길 여러 파일 이름을 일괄 구성합니다. 접두사·접미사, 파일명 본문의 찾기/바꾸기, 시작 번호와 자릿수를 적용하고 확장자를 보존합니다. 중복 이름은 `(2)`처럼 구분합니다.
- **활용·사용:** 사진이나 문서 묶음의 이름 규칙을 통일할 때 씁니다. 파일을 선택한 뒤 옵션을 조정하고 미리보기 표에서 이전/새 이름을 확인한 다음 실행합니다.
- **예제:** `photo-1.jpg`의 접두사에 `trip-`을 지정하면 `trip-photo-1.jpg`가 됩니다. 시작 번호를 `1`, 자릿수를 `3`으로 지정하면 이름 끝에 `001`부터 순번이 붙습니다.
- **제한·문제 해결:** 최대 100개·200MB를 처리합니다. 금지된 경로 문자는 `_`로 바뀌고, 압축 파일을 다운로드해야 새 이름이 적용됩니다. 같은 이름이 나오면 중복 꼬리표를 확인하세요.
- **FAQ:** 내 컴퓨터의 원본 이름을 직접 바꾸나요? 아니요. 새 이름으로 ZIP을 만들며 원본은 그대로 둡니다. / 확장자도 찾기/바꾸기 하나요? 찾기/바꾸기는 확장자를 제외한 파일명 본문에 적용하고 확장자는 유지합니다.

## filename-cleaner

- **소개·원리:** 파일명을 Unicode NFKC로 정규화하고 금지 문자를 제거하며 공백을 밑줄로 바꿔 ZIP에 넣습니다. 안전한 아카이브 이름이 겹치면 고유한 이름을 만듭니다.
- **활용·사용:** `?`, `:` 같은 파일명 문자를 정리해 공유용 파일 묶음을 만들 때 사용합니다. 여러 파일을 선택해 실행한 뒤 변환 전후 이름 목록과 ZIP을 확인합니다.
- **예제:** `my photo?.jpg`는 `my_photo.jpg`가 됩니다. 내용 바이트는 그대로 보존됩니다.
- **제한·문제 해결:** 최대 100개·총 200MB입니다. 정리 후 이름이 비거나 충돌하면 안전 이름 또는 번호 꼬리표가 붙을 수 있습니다. 출력 ZIP에서 실제 이름을 확인하세요.
- **FAQ:** 파일 내용을 바꾸나요? 아니요. ZIP 안의 파일명만 정리하고 바이트는 복사합니다. / 원본을 덮어쓰나요? 아니요. 새 ZIP을 내려받습니다.

## lorem-ipsum

- **소개·원리:** 레이아웃 시안용으로 고정된 Lorem ipsum 문단을 선택한 개수만큼 반복해 만듭니다.
- **활용·사용:** 실제 문구가 준비되기 전 화면의 세로 길이나 문단 간격을 확인할 때 씁니다. 문단 수를 1~20으로 지정하고 생성합니다.
- **예제:** 3을 선택하면 `Lorem ipsum dolor sit amet, consectetur adipiscing elit. Sed do eiusmod tempor incididunt ut labore et dolore magna aliqua.` 문단이 세 개, 빈 줄로 나뉘어 출력됩니다.
- **해석·제한:** 각 문단은 같은 고정 문장입니다. 다양한 문장이나 실제 의미를 가진 카피를 만들지 않으며 최대 20개입니다. 임의 문장이나 글자 수 설정은 제공하지 않습니다.
- **FAQ:** 매번 다른 문장을 생성하나요? 아니요. 동일한 고정 문장을 반복합니다. / 실제 게시용 문장인가요? 아니요. 레이아웃 임시 문구입니다.

## regex-tester

- **소개·원리:** 첫 입력에서 `/패턴/플래그` 형식의 정규식을 받고 두 번째 입력의 샘플에서 일치 항목을 찾습니다. 정규식은 별도 브라우저 Worker에서 제한 시간 안에 실행됩니다.
- **활용·사용:** 텍스트 형식 확인이나 패턴 초안 실험에 씁니다. 예를 들어 `/\d+/g`와 `A12`를 입력하면 `12 (index 1)`을 얻습니다.
- **해석:** 전역 탐색으로 최대 100개 결과를 보여 주며 각 결과에 샘플 내 시작 인덱스를 붙입니다. 입력한 플래그에 `g`가 없으면 도구가 전역 플래그를 추가합니다.
- **제한·문제 해결:** 패턴 최대 200자, 샘플 최대 20,000자, 실행 제한 250ms입니다. 중첩 반복과 역참조는 안전을 위해 거부됩니다. 패턴은 `/패턴/플래그`로 감싸고 유효한 플래그를 사용하세요.
- **FAQ:** 일치 부분을 바꾸나요? 아니요. 일치 항목과 위치만 표시합니다. / 모든 결과를 표시하나요? 최대 100개이며 시간 제한을 넘으면 중단됩니다.
