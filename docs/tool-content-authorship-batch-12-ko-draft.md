## barcode-generator

- **소개:** 입력한 텍스트나 숫자로 스캔 가능한 막대 패턴을 만들고, SVG 파일로 내려받는 도구입니다. CODE128과 EAN-13 형식을 선택할 수 있습니다.
- **원리:** 브라우저에서 JsBarcode가 선택한 심볼 규격에 맞춰 SVG를 그립니다. 선 색은 진한 회색, 배경은 흰색이며, 아래에 값도 표시합니다.
- **활용:** 재고 라벨의 짧은 식별값을 출력하거나 테스트용 EAN-13 샘플을 빠르게 시각화할 때 사용합니다. 생성 결과가 실제 상품 등록이나 유통 식별을 의미하지는 않습니다.
- **사용:** 값을 입력하고 CODE128 또는 EAN-13을 선택한 뒤 생성 버튼을 누릅니다. 오류가 없다면 결과를 확인하고 `barcode.svg`를 저장합니다.
- **예제:** CODE128에 `ABC123`을 넣으면 해당 문자열 아래에 표시된 SVG 막대 코드가 생성됩니다. EAN-13은 예시 `4006381333931`을 사용하고 브라우저 렌더링을 확인합니다.
- **해석:** SVG에는 스캔할 막대와 입력 문자열이 함께 표시됩니다. 인쇄할 때는 주변 여백과 충분한 대비를 유지하고 실제 스캐너로 확인합니다.
- **제한·해결:** 입력은 최대 80자이며, 선택한 규격에서 허용하지 않는 값은 생성 오류가 납니다. EAN-13에서 길이·숫자·검사 숫자 오류가 나면 12자리 본문 또는 올바른 13자리 번호인지 확인합니다. 체크 숫자가 맞아도 상품의 진위나 등록 여부는 검증하지 않습니다.
- **FAQ:** CODE128과 EAN-13 외 형식을 만들 수 있나요? 현재 화면에서 선택할 수 있는 형식은 두 가지입니다. / 결과를 PNG로 저장할 수 있나요? 현재 다운로드는 SVG입니다.

## social-image-resize

- **소개:** 사진을 소셜 게시물과 영상 표지에 맞춘 고정 크기의 JPEG로 변환합니다. 비율이 다른 원본은 가운데를 기준으로 잘라 대상 비율에 맞춥니다.
- **원리:** 원본을 선택한 대상 캔버스를 채우도록 확대하고 중앙 영역을 잘라 1080×1080 정사각형, 1080×1350 세로 게시물, 1080×1920 스토리, 1280×720 YouTube, 1600×900 X, 1200×630 Facebook 크기로 그립니다.
- **활용:** 여러 플랫폼에 올릴 사진의 크기와 구도를 빠르게 맞추거나 게시물용 파생 파일을 만들 때 사용합니다.
- **사용:** 사진을 선택하고 플랫폼 프리셋을 고른 다음 처리를 실행해 결과 크기와 파일을 확인하고 내려받습니다.
- **예제:** 1600×1200 사진을 Facebook 프리셋으로 처리하면 결과 캔버스는 1200×630 JPEG입니다. 가로세로 비율을 맞추기 위해 세로 일부가 중앙 기준으로 잘립니다.
- **해석:** 결과 픽셀 크기는 프리셋 값과 같지만 피사체 주변 가장자리는 잘릴 수 있습니다. 게시 전 얼굴, 로고, 문구 위치를 확인합니다.
- **제한·해결:** 이미지 도구는 파일당 30MB 및 디코딩 4천만 픽셀 제한을 적용합니다. 잘림이 원치 않는 부분을 가리면 다른 프리셋을 선택하거나 원본 구도를 조정하세요. 이 도구는 플랫폼 계정에 게시하지 않습니다.
- **FAQ:** 원본 비율이 유지되나요? 아니요. 캔버스를 채우기 위해 중앙을 자릅니다. / 어떤 형식으로 저장되나요? 이 도구의 결과는 JPEG입니다.

## add-text-to-image

- **소개:** 사진 아래쪽 중앙에 짧은 문구 한 줄을 얹어 JPEG 결과를 만드는 도구입니다.
- **원리:** 브라우저 캔버스에 원본을 그리고 흰색 굵은 글자를 검은 외곽선과 함께 하단 중앙에 그립니다. 글꼴 크기는 짧은 변의 약 6%를 기준으로 정하고 가로 폭의 90% 안에 맞춥니다.
- **활용:** 사진에 간단한 캡션, 이름, 날짜를 표시한 별도 공유용 이미지를 만들 때 사용합니다.
- **사용:** 사진을 선택하고 160자 이내 문구를 입력한 뒤 실행합니다. 생성된 JPEG를 확인하고 원본과 별도로 저장합니다.
- **예제:** 사진과 `Weekend market`을 입력하면 흰 글자와 검은 외곽선 문구가 아래 중앙에 그려진 JPEG가 생성됩니다.
- **해석:** 문구는 하단 한 줄로 배치되고 긴 텍스트는 지정된 최대 폭에 맞춰 축소됩니다. 중요한 피사체나 자막과 겹치는지 확인합니다.
- **제한·해결:** 빈 문구는 처리할 수 없고 길이는 160자로 제한됩니다. 결과가 너무 작거나 읽기 어려우면 문구를 짧게 줄이고, 하단 배경이 복잡하면 대비를 직접 확인하세요. 위치나 글꼴을 설정하는 기능은 없습니다.
- **FAQ:** 문구 위치나 색상을 바꿀 수 있나요? 현재는 하단 중앙의 흰색 글자와 검은 외곽선으로 고정됩니다. / 원본 파일도 바뀌나요? 아니요. 별도의 결과 이미지를 만듭니다.

## instagram-grid-split

- **소개:** 이미지 한 장을 3·6·9개의 순서가 있는 정사각형 조각으로 나눠 ZIP 파일로 제공합니다.
- **원리:** 선택한 타일 배열의 전체 가로세로 비율에 맞춰 원본 중앙을 자른 뒤 각 조각을 별도 이미지로 만들고 ZIP에 담습니다. 배열은 3열이며 각각 3×1, 3×2, 3×3 타일입니다.
- **활용:** 프로필 격자에 이어 붙일 대형 이미지를 미리 분할하거나 타일별 게시 순서를 준비할 때 사용합니다.
- **사용:** 가로·세로 이미지 한 장을 올리고 타일 수 3, 6, 9 중 하나를 선택한 뒤 실행합니다. ZIP을 풀어 번호 순서대로 각 타일을 확인합니다.
- **예제:** 1200×1200 정사각형을 9개로 나누면 중앙 전체가 3×3 격자로 분할되고 9개 파일이 ZIP에 담깁니다.
- **해석:** 결과 조각은 배열 순서대로 파일명이 붙으며, 게시 플랫폼의 표시 방식이나 업로드 순서는 도구가 제어하지 않습니다.
- **제한·해결:** 지원 타일 수는 3, 6, 9입니다. 비율이 맞지 않는 원본은 격자 전체 비율에 맞춰 가운데가 잘릴 수 있습니다. ZIP을 연 뒤 번호와 연결 방향을 확인하고 업로드하세요.
- **FAQ:** 사진 여러 장을 합치나요? 아니요. 입력 이미지 한 장을 조각냅니다. / 게시물도 자동으로 올리나요? 아니요. ZIP 다운로드만 제공하며 업로드는 직접 해야 합니다.

## image-collage

- **소개:** 여러 사진을 흰 간격이 있는 정사각형 셀에 배열해 한 장의 JPEG 콜라주를 만듭니다.
- **원리:** 2열×2행 또는 3열×2행 고정 격자를 사용합니다. 각 사진은 중앙 기준으로 잘라 480×480 셀에 맞추고 셀 사이에는 12px 흰 간격을 둡니다. JPEG 품질 슬라이더 기본값은 82%입니다.
- **활용:** 몇 장의 사진을 비교용 모음이나 간단한 공유 이미지 한 장으로 정리할 때 사용합니다.
- **사용:** 사진 2~4장(2열 배치) 또는 2~6장(3열 배치)을 고르고 레이아웃과 JPEG 품질을 정한 뒤 콜라주를 만듭니다. 내려받기 전 배치와 잘림을 확인합니다.
- **예제:** 사진 4장을 2열×2행으로 처리하면 996×996 픽셀 JPEG가 생성됩니다(셀 960px와 좌우·상하 간격 36px).
- **해석:** 제공된 사진은 선택 순서대로 왼쪽에서 오른쪽, 위에서 아래로 배치됩니다. 빈 셀은 흰색으로 남습니다.
- **제한·해결:** 최대 6장, 선택 파일 합계 100MB, 디코딩된 총 8천만 픽셀 제한이 있습니다. 지원 이미지를 열 수 없거나 용량 제한 오류가 나면 파일 수와 크기를 줄이세요. 각 셀은 중앙을 잘라 채우므로 가장자리를 확인합니다.
- **FAQ:** 사진을 셀 안에 전부 맞춰 넣나요? 아니요. 정사각형에 채우기 위해 중앙을 자릅니다. / 품질을 조정할 수 있나요? 네. JPEG 품질을 조절할 수 있습니다.
