# Batch 15 Korean editorial drafts

Drafts reflect `processText` and its lazy browser-side formatter/parser dependencies.

## color-converter

- **소개·원리:** HEX 3/6자리, `rgb(r, g, b)`, `hsl(h, s%, l%)` 중 하나를 받아 같은 색을 HEX, RGB, HSL로 표시합니다. HEX는 대문자 6자리로 정규화하고 HSL은 정수로 반올림합니다.
- **활용·사용:** 디자인 시안이나 CSS 색상 값을 다른 표기법에 맞춰 옮길 때 씁니다. 색상 값을 입력하고 실행한 뒤 세 줄의 결과를 복사합니다.
- **예제:** `#ff0000` → `HEX: #FF0000`, `RGB: rgb(255, 0, 0)`, `HSL: hsl(0, 100%, 50%)`.
- **제한·문제 해결:** CSS 색상 이름, 투명도/알파, 8자리 HEX는 지원하지 않습니다. RGB 각 값은 0–255, HSL 채도와 명도는 0–100%여야 합니다. 허용된 형식의 괄호·쉼표·퍼센트 표기를 확인하세요.
- **FAQ:** `red`나 `#ff000080`을 입력해도 되나요? 아니요. 색상 이름과 알파 채널은 파싱하지 않습니다. / HSL의 색조가 360이면 어떻게 되나요? 계산에서 0도와 같은 빨강 계열로 순환합니다.

## cron-parser

- **소개·원리:** 입력한 5필드 또는 6필드 Cron 식을 `cron-parser`로 해석하고 다음 다섯 실행 시각을 브라우저의 현재 로컬 시간대로 표시합니다. 식을 실행하거나 예약하지는 않습니다.
- **활용·사용:** 기존 스케줄의 다음 실행 시각을 미리 살펴볼 때 사용합니다. 식을 입력하고 실행해 원래 식과 다섯 시각을 비교합니다.
- **예제:** `0 9 * * 1`은 매주 월요일 09:00에 해당하는 다음 다섯 시각을 보여 줍니다. 실제 날짜와 표시는 실행 당시의 현재 날짜·기기 시간대에 따라 달라집니다.
- **제한·문제 해결:** 서버 작업을 등록하거나 저장하지 않습니다. 시간대 선택 입력은 없으며 현재 기기의 로컬 시간대를 사용합니다. 필드 수, 범위, 요일/월 표기를 확인하고 의도한 스케줄과 결과를 대조하세요.
- **FAQ:** 이 도구가 작업을 실행하나요? 아니요. Cron 식을 검사하고 예정 시각만 계산합니다. / UTC로 결과를 볼 수 있나요? 별도 시간대 선택은 없고 기기의 로컬 시간으로 표시합니다.

## sql-formatter

- **소개·원리:** 입력 SQL을 `sql-formatter`의 기본 SQL 언어 설정으로 들여쓰기와 줄바꿈을 정리합니다. 쿼리를 데이터베이스에 전송하거나 실행하지 않습니다.
- **활용·사용:** 한 줄로 붙어 있는 쿼리를 읽기 쉽게 정돈해 검토하거나 문서에 붙여 넣을 때 유용합니다. SQL을 입력하고 실행한 뒤 결과를 확인합니다.
- **예제:** `select id from users`는 `SELECT id\nFROM users` 형태로 정리됩니다.
- **제한·문제 해결:** SQL 방언 선택 옵션은 없습니다. 포맷은 의미를 검증하거나 쿼리 실행 결과를 보장하지 않습니다. 문법 오류가 나타나면 입력 SQL의 괄호, 따옴표와 구문을 확인하세요.
- **FAQ:** 데이터베이스에 연결하나요? 아니요. 브라우저에서 텍스트만 포맷합니다. / SQL 방언을 고를 수 있나요? 현재 기본 `sql` 설정으로 처리하며 방언 선택 UI는 없습니다.

## html-formatter

- **소개·원리:** Prettier HTML 파서로 마크업에 들여쓰기와 줄바꿈을 적용합니다. HTML을 브라우저에 삽입해 실행하지 않습니다.
- **활용·사용:** 붙어 있는 요소의 계층을 눈으로 검토할 수 있도록 입력 코드를 정돈합니다. HTML을 붙여 넣고 실행한 뒤 정리된 결과를 살펴봅니다.
- **예제:** `<div><p>Hello</p></div>`는 부모 `div`와 자식 `p`가 들여쓰기된 여러 줄로 표시됩니다.
- **제한·문제 해결:** 출력 줄 너비는 100열 설정입니다. 포맷은 HTML 유효성 검사나 보안 검사가 아닙니다. 파싱 오류가 나면 열린 태그·속성 따옴표와 입력이 잘리지 않았는지 확인하세요.
- **FAQ:** 입력 HTML을 페이지에 렌더링하나요? 아니요. 코드를 텍스트로 포맷합니다. / 오류가 사라지면 유효한 HTML인가요? 아니요. 정렬 성공은 유효성이나 브라우저 동작을 인증하지 않습니다.

## css-formatter

- **소개·원리:** Prettier PostCSS 플러그인으로 CSS를 파싱하고 들여쓰기·공백·줄바꿈을 정리합니다.
- **활용·사용:** 축약된 규칙을 선택자와 선언별로 읽기 쉽게 만들어 검토하거나 공유할 때 사용합니다. CSS를 입력하고 실행합니다.
- **예제:** `h1{color:red}`는 `h1 {\n  color: red;\n}` 형태로 정리됩니다.
- **제한·문제 해결:** 줄 너비는 100열입니다. 이 도구는 CSS를 웹페이지에 적용하거나 스타일 결과를 미리 보지 않습니다. 구문 오류가 나면 중괄호, 콜론, 세미콜론을 확인하세요.
- **FAQ:** 색상이나 레이아웃을 미리 볼 수 있나요? 아니요. 코드를 정리한 텍스트만 제공합니다. / 압축 파일을 만들 수 있나요? 아니요. CSS 텍스트 결과를 확인하거나 복사합니다.
