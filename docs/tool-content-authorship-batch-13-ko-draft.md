## file-hash

- **소개·원리:** 선택한 각 파일의 전체 바이트를 Web Crypto `SHA-256`으로 계산하고 파일명, 알고리즘, 16진수 해시를 표로 보여줍니다. 파일 내용은 브라우저 안에서 처리됩니다.
- **활용:** 받은 파일의 지문을 비교하거나 다른 도구가 요구한 SHA-256 값을 확인할 때 사용합니다. 동일한 바이트는 같은 해시를 갖지만, 해시가 파일의 안전성이나 출처를 보증하지 않습니다.
- **사용·예제:** 파일을 하나 이상 선택하고 실행합니다. UTF-8 텍스트 `hello`의 SHA-256 예시는 `2cf24dba5fb0a30e26e83b2ac5b9e29e1b161e5c1fa7425e73043362938b9824`입니다. 파일명별 결과를 복사해 기준값과 비교합니다.
- **해석:** 결과는 해당 파일 전체의 SHA-256 지문입니다. 같은 파일이라도 바이트가 하나 달라지면 보통 해시가 달라집니다.
- **제한·해결:** 한 번에 최대 100개, 총 200MB까지 선택할 수 있습니다. 같은 이름의 파일이라도 내용이 다를 수 있으므로 이름 대신 해시를 비교하세요. 이 도구는 바이러스 검사나 서명 검증기가 아닙니다.
- **FAQ:** MD5나 SHA-1을 계산하나요? 현재 결과는 SHA-256입니다. / 파일을 서버로 보내나요? 해시는 브라우저에서 계산됩니다.

## mime-type-checker

- **소개·원리:** 브라우저가 제공한 MIME 유형과 파일 앞부분의 간단한 시그니처를 함께 표시합니다. 현재 알려진 시그니처는 PNG, JPEG, PDF, GIF, ZIP이며 나머지는 `Unknown signature`로 보고합니다.
- **활용:** 파일 유형을 빠르게 살펴보거나 확장자와 브라우저 MIME 표기가 예상과 다른지 사람이 비교할 때 사용합니다.
- **사용·예제:** 파일을 선택하고 검사합니다. MIME이 `image/png`인 PNG는 `image/png`와 `PNG signature`처럼 표시됩니다.
- **해석:** MIME은 브라우저가 파일 객체에서 알려 준 값이고 시그니처는 앞의 일부 바이트만 확인한 결과입니다. 둘이 다르거나 알 수 없음이 나와도 파일 전체를 분석한 진단은 아닙니다.
- **제한·해결:** 시그니처 판별은 일부 형식에만 적용되며, 파일의 실제 안전성·유효성·내용을 보증하지 않습니다. 결과가 불분명하면 신뢰할 수 있는 응용프로그램으로 파일을 확인하세요.
- **FAQ:** 확장자가 틀렸으면 자동 수정하나요? 아니요. MIME과 시그니처만 나열합니다. / 모든 파일 형식을 알아내나요? 아니요. 등록되지 않은 서명은 알 수 없음으로 표시합니다.

## file-extension-checker

- **소개·원리:** 파일명에서 마지막 점 뒤 문자열을 소문자로 정리해 확장자를 표시하고, 브라우저가 제공한 MIME 유형을 나란히 보여줍니다.
- **활용:** 파일 목록에서 이름의 확장자와 브라우저 MIME 표기를 직접 비교하는 데 씁니다. 자동 불일치 판정이나 확장자 변경은 하지 않습니다.
- **사용·예제:** `report.PDF` 같은 파일을 선택하면 확장자는 `.pdf`, MIME은 브라우저가 제공하는 값으로 표시됩니다. MIME이 비어 있을 수 있습니다.
- **해석:** 확장자는 이름에서 읽은 문자열이며 실제 내용 검증 결과가 아닙니다. `.pdf`라고 해서 유효한 PDF라는 뜻은 아닙니다.
- **제한·해결:** 점이 없는 이름은 `(none)`으로 나오며 마지막 확장자만 표시합니다. 여러 점이 있으면 마지막 점 뒤만 사용합니다. 불일치는 결과를 보고 사용자가 판단하세요.
- **FAQ:** 확장자를 바꾸거나 파일을 고치나요? 아니요. 목록만 표시합니다. / MIME과 확장자가 달라도 오류로 표시하나요? 별도 경고 없이 두 값을 나란히 보여줍니다.

## file-size-checker

- **소개·원리:** 선택한 각 파일의 바이트 수를 읽어 1024 단위로 B, KB 또는 MB 표시로 바꿉니다.
- **활용:** 업로드 전 여러 파일의 개별 크기를 확인하거나 파일 선택이 제한에 걸릴지 가늠할 때 유용합니다.
- **사용·예제:** 파일을 하나 이상 선택하고 실행합니다. 1536바이트 파일은 `1.5 KB`로 표시됩니다.
- **해석:** 결과는 선택한 각 파일의 크기 목록입니다. 도구는 합계 행이나 압축 후 크기를 계산하지 않습니다.
- **제한·해결:** 최대 100개, 파일 합계 200MB까지 선택할 수 있습니다. 제한을 넘으면 파일 수나 크기를 줄여 다시 선택하세요. 이 값은 파일 크기만 나타내며 저장 장치 사용량이나 전송 후 크기는 다를 수 있습니다.
- **FAQ:** 여러 파일의 총합도 보여주나요? 현재는 파일별 값만 표시합니다. / 파일을 압축하나요? 아니요. 크기를 읽어 보고합니다.

## duplicate-file-checker

- **소개·원리:** 각 파일의 전체 바이트에서 SHA-256을 계산하고 같은 해시를 가진 파일명끼리 그룹화합니다. 내용이 바이트 단위로 같은 파일을 찾습니다.
- **활용:** 서로 다른 이름으로 저장된 동일 파일 후보를 정리하거나 복사본을 비교할 때 사용합니다.
- **사용·예제:** 파일들을 여러 개 선택해 실행합니다. 같은 바이트를 가진 `copy-a.txt`와 `copy-b.txt`는 같은 그룹으로 표시됩니다. 중복이 없으면 중복 파일을 찾지 못했다는 결과를 받습니다.
- **해석:** 일치 그룹은 파일 내용이 동일하다는 강한 지표입니다. 파일명이 같다는 이유만으로 중복 처리하지 않으며, 크기가 같은 것만으로도 중복을 판정하지 않습니다.
- **제한·해결:** 최대 100개, 총 200MB까지 처리합니다. 결과는 해시 그룹의 파일명을 알려 주며 자동 삭제나 병합은 하지 않습니다. 해시 비교는 악성코드 검사나 출처 인증이 아닙니다.
- **FAQ:** 이름이 다르면 중복을 못 찾나요? 찾을 수 있습니다. 내용 해시로 묶습니다. / 중복 파일을 자동 삭제하나요? 아니요. 결과를 보고 직접 관리합니다.
