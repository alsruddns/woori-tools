# Batch 19 Korean editorial drafts

All five tools decode the image locally, draw it on Canvas, and create a separate JPEG. Inputs are limited to 30 MB and 40 million decoded pixels; source files are not overwritten.

## image-brightness

- **소개와 원리:** Canvas의 brightness 필터를 슬라이더 비율로 적용해 이미지를 다시 그립니다. 기본값 25%이며 픽셀 크기는 유지됩니다.
- **활용과 절차:** 어두운 사진의 밝기를 비교하려면 파일을 고르고 밝기 값을 조정해 실행한 뒤 별도 JPEG를 확인하세요.
- **예제:** 12×8 이미지와 100%는 중립 밝기, 25%는 어두운 결과, 200%는 더 밝은 결과를 냅니다.
- **제한과 결과:** 값은 0–200%이고 100%가 원래 밝기입니다. 노출 복구나 영역별 편집은 하지 않습니다.
- **FAQ:** 원본 파일을 덮어쓰나요? / 아니요. 조정된 JPEG를 별도로 다운로드합니다.

## image-contrast

- **소개와 원리:** Canvas contrast 필터로 명암 차이를 조정한 뒤 같은 픽셀 크기의 JPEG를 출력합니다.
- **활용과 절차:** 대비가 약한 사진을 시험하려면 슬라이더를 조정해 실행하고 어두운 영역과 밝은 영역을 비교하세요.
- **예제:** 기본 25%는 100%보다 낮은 대비입니다. 100%는 중립 값이고 200%는 대비를 높입니다.
- **제한과 결과:** 슬라이더는 0–200%입니다. 색상 곡선·선택 영역 조절이나 원본 복구는 제공하지 않습니다.
- **FAQ:** 기본값이 중립 대비인가요? / 아니요. 기본 25%이며 중립값은 100%입니다.

## image-blur

- **소개와 원리:** CSS Canvas blur 필터를 적용합니다. 슬라이더 값을 10으로 나눈 픽셀 반경을 사용하며 기본 25는 2.5px 흐림입니다.
- **활용과 절차:** 작은 글자나 배경을 부드럽게 하려면 이미지를 선택하고 흐림 값을 조정해 미리 결과를 확인하세요.
- **예제:** 0은 흐림 없음, 25는 2.5px, 100은 10px 반경입니다. 이미지 픽셀 크기는 유지됩니다.
- **제한과 결과:** 전체 이미지에 필터가 적용되며 특정 부분만 흐리는 마스크는 없습니다. 출력은 별도 JPEG입니다.
- **FAQ:** 일부 영역만 흐릴 수 있나요? / 아니요. 이 도구는 전체 이미지에 흐림 필터를 적용합니다.

## image-pixelate

- **소개와 원리:** 작은 임시 캔버스에 축소해 그린 다음 이미지 스무딩을 끄고 원래 크기로 확대해 블록 효과를 만듭니다.
- **활용과 절차:** 모자이크 효과를 비교하려면 슬라이더를 조절하고 실행한 뒤 픽셀 블록 크기를 확인하세요.
- **예제:** 120×80 이미지에서 값 20은 축소 캔버스를 약 6×4픽셀로 만들고 다시 확대합니다.
- **제한과 결과:** 값은 4–80이고 클수록 축소 캔버스가 작아져 더 큰 블록이 보입니다. 선택 영역만 처리하지 않습니다.
- **FAQ:** 숫자가 클수록 모자이크가 촘촘해지나요? / 아니요. 값이 클수록 더 큰 픽셀 블록이 생깁니다.

## remove-image-metadata

- **소개와 원리:** 이미지를 Canvas에서 JPEG로 다시 인코딩해 EXIF/GPS 같은 원본 메타데이터를 결과 파일에 복사하지 않습니다.
- **활용과 절차:** 공유 전 위치 정보가 든 사진을 정리하려면 파일을 선택하고 실행한 뒤 별도 JPEG를 다운로드하세요.
- **예제:** JPEG나 PNG 입력 → 같은 픽셀 크기의 JPEG 사본. 결과는 JPEG 형식입니다.
- **제한과 결과:** 재인코딩은 원래 형식과 품질을 바꿀 수 있습니다. 이미지 픽셀에 덧씌워진 글자나 얼굴은 제거하지 않습니다.
- **문제 해결과 FAQ:** 메타데이터 제거를 원본 파일에 적용하나요? / 아니요. 새 JPEG를 만들며 원본은 유지됩니다. 모든 메타데이터 계층의 포렌식 제거를 보증하지 않으므로 민감한 이미지라면 결과를 별도 도구로 확인하세요.
