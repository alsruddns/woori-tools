## timer
- 소개/원리: 시·분·초로 지정한 시간을 브라우저에서 카운트다운합니다. 0이 되면 화면에 종료 상태를 표시합니다.
- 활용/방법: 조리, 공부, 짧은 운동에 맞는 시·분·초를 입력하고 시작합니다. 진행 중에는 일시 정지하거나 이어서 실행할 수 있습니다.
- 예제/결과: 10초를 설정하면 표시가 `00:00:10`부터 감소해 0에서 멈추고 시간 종료 메시지가 나타납니다.
- 제한/문제 해결: 알림음이나 반복 실행을 제공하지 않습니다. 시간이 줄지 않으면 시작 상태인지 확인하고, 탭이 백그라운드에 있을 때는 브라우저의 타이머 갱신이 늦어질 수 있습니다.
- FAQ: 종료 시 소리가 나나요? 화면에 종료 상태를 보여 주며 소리 알림은 없습니다.

## pomodoro-timer
- 소개/원리: 집중 25분과 휴식 5분을 선택해 카운트다운합니다. 모드 버튼으로 집중/휴식 시간을 전환하며 전환은 사용자가 직접 합니다.
- 활용/방법: 집중 모드에서 시작하고 시간이 끝나면 휴식 버튼을 눌러 5분을 시작합니다. 휴식이 끝나면 집중으로 전환합니다.
- 예제/결과: 기본 집중 시간은 25:00, 휴식은 05:00입니다. 각 카운트다운은 0에서 종료 메시지를 표시합니다.
- 제한/문제 해결: 집중·휴식 시간은 고정이며 자동 순환, 회차 기록, 알림음은 없습니다. 전환이 안 되면 실행 중인지 확인하고 먼저 일시 정지합니다.
- FAQ: 집중과 휴식이 자동으로 바뀌나요? 아니요. 매 단계가 끝난 뒤 직접 모드를 선택하고 다시 시작합니다.

## world-clock
- 소개/원리: IANA 시간대 기준으로 여러 지역의 현지 시각과 날짜를 초 단위로 표시합니다.
- 활용/방법: 기본 도시 시계를 확인하거나 시간대를 검색해 선택한 뒤 도시 추가를 누릅니다. 더는 필요 없는 시계는 삭제합니다.
- 예제/결과: 기본 목록에는 서울, 도쿄, 뉴욕, 로스앤젤레스, 런던, 파리, 싱가포르, 시드니가 있습니다. `Europe/London`을 추가하면 영국 현지 시각과 날짜가 표시됩니다.
- 제한/문제 해결: 최대 20개 시간대를 표시하고 선택 목록은 이 브라우저의 localStorage에 저장됩니다. 시각은 UTC 오프셋을 직접 더하는 방식이 아니라 시간대 규칙과 서머타임을 반영합니다. 목록이 비면 시간대를 검색해 다시 추가합니다.
- FAQ: 도시 목록이 새로고침 후에도 유지되나요? 같은 브라우저 저장 공간에서 복원할 수 있지만 다른 기기와 동기화되지는 않습니다.

## password-generator
- 소개/원리: 브라우저 Web Crypto 난수로 선택한 문자 그룹을 포함하는 비밀번호 하나를 만듭니다.
- 활용/방법: 길이와 대문자·소문자·숫자·특수문자 그룹을 선택하고 필요하면 헷갈리기 쉬운 O, 0, I, l, 1을 제외한 뒤 생성합니다.
- 예제/결과: 기본 길이는 16자이며 네 문자 그룹을 모두 켜면 각 그룹에서 최소 한 글자씩 포함하고 나머지 위치는 선택된 그룹에서 채웁니다.
- 제한/문제 해결: 길이는 4~256자 범위로 처리하며 적어도 한 문자 그룹을 골라야 합니다. 생성된 값은 화면에 표시되고 서버로 보내지지 않습니다. 사이트가 허용하는 문자와 길이 제한을 확인하세요.
- FAQ: 생성할 때마다 같은 비밀번호가 나오나요? 아니요. 난수 결과는 실행마다 달라질 수 있습니다.

## random-string-generator
- 소개/원리: 선택한 문자 그룹으로 지정 길이의 문자열을 여러 개 생성합니다. Web Crypto 난수를 사용하고 각 선택 그룹의 문자를 최소 한 번 포함한 뒤 문자를 섞습니다.
- 활용/방법: 문자열 길이와 개수를 입력하고 포함할 대문자·소문자·숫자·특수문자 및 비슷한 문자 제외 여부를 선택한 뒤 생성합니다.
- 예제/결과: 길이 12, 개수 3, 네 그룹 선택이면 길이 12인 결과 세 줄이 만들어집니다. 각 줄은 네 그룹의 문자를 각각 하나 이상 포함합니다.
- 제한/문제 해결: 길이는 4~256자, 개수는 1~100개로 제한됩니다. 문자 그룹을 모두 끄면 오류가 표시됩니다. 생성 문자열의 중복 여부는 보장하지 않습니다.
- FAQ: 같은 결과가 두 번 나올 수 있나요? 가능합니다. 생성 개수와 문자 공간에 따라 서로 같은 문자열이 나올 수 있습니다.
